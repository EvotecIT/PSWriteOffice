# PSWriteOffice has moved to OfficeIMO

> [!IMPORTANT]
> **[OfficeIMO](https://github.com/EvotecIT/OfficeIMO) is the home for development, releases, issues, and pull requests for OfficeIMO and PSWriteOffice.**
>
> **[Report an issue](https://github.com/EvotecIT/OfficeIMO/issues) · [Contribute](https://github.com/EvotecIT/OfficeIMO) · [PowerShell source and examples](https://github.com/EvotecIT/OfficeIMO/tree/master/PowerShell/PSWriteOffice)**

This repository is archived for historical reference. All new bug reports, feature requests, and contributions belong in [OfficeIMO](https://github.com/EvotecIT/OfficeIMO).

PSWriteOffice is the PowerShell module maintained alongside the OfficeIMO engines. Install it from the PowerShell Gallery:

```powershell
Install-Module PSWriteOffice -Scope CurrentUser
Import-Module PSWriteOffice
```

Use the [PowerShell guide](https://officeimo.com/docs/pswriteoffice/), [command reference](https://officeimo.com/api/powershell/), and [examples](https://github.com/EvotecIT/OfficeIMO/tree/master/PowerShell/PSWriteOffice/Examples) for the current API. PSWriteWord and PSWriteExcel scripts may need API changes when migrating to PSWriteOffice.
